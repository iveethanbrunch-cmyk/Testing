x(t−τ): τ>0 shifts RIGHT. x(αt): |α|>1 compresses

Trap: Check y(0) = x(2).

5Convolution and impulse responsemid-sem, 2024 Q2

y[n] = Σ x[k]h[n−k]. y(t) = ∫x(τ)h(t−τ)dτ
Needs: LTI.
Trap: Flip h, then slide. Split into overlap cases.
Support of x∗h = [a₁+a₂, b₁+b₂]
Needs: Finite lengths: L₁+L₂−1 samples.
FIR equation y = Σbₖx[n−k] ⇒ h = Σbₖδ[n−k]
Trap: Mock Q1: h = δ[n] − 0.5δ[n−1] − 0.5δ[n−2] + δ[n−3].
x∗δ(t−t₀) = x(t−t₀): each delta in h gives a delayed copy of x
Trap: h = δ(t−1)−δ(t−2)+δ(t−3) ⇒ y = x(t−1)−x(t−2)+x(t−3). Stable (finite impulses).
Step response s = h∗u; h = ds/dt. y with u input: s(t) = u(t−1)−u(t−2)+u(t−3) for the h above
Past paper: 2024 Q2: z=u(t+1)−u(t−1), Ts=2/3 ⇒ x[−2..1] = 0,1,1,1 (x=1 for n=−1,0,1). y[n] = Σk=−11 h[n−k] ⇒ A=−1, B=1. Q2c diagram (final gain 0.1): a=1, b=2, c=10, d=0.5.

6Fourier series questions2022 Q3, 2024 Q4, mock Q3–4, sample Q8

X₀ = (1/T₀)∫ one period of x = average value
Trap: Duty cycle β, height 1 ⇒ X₀ = β.
Periodic x through LTI: Yₖ = H(kω₀)Xₖ. DC: Y₀ = H(0)X₀
Needs: Stable LTI.
Trap: ω₀ = 2π/T₀, not 2π/T of some other signal.
H(0) = ∫h(t)dt (= DC gain)
Trap: h = e−2tu − e−4tu ⇒ H(0) = 1/2 − 1/4 = 1/4.
Which harmonics pass a filter: list kω₀ for k = ±1, ±2, … and compare with the passband
Needs: Include negative k.
Trap: Two or more pairs pass ⇒ output is not a single cosine.
Real x, pair ±k passes: y = 2|Xₖ| cos(kω₀t + ∠Xₖ)
Parseval: (1/T₀)∫|x|² = Σ|Xₖ|². Real x: Σk≥1|Xₖ|² = (P − |X₀|²)/2
Trap: Mid-sem: P = 4, X₀ = 0 ⇒ 2.
Modulation by cos(Mω₀t): Wₖ = ½Xₖ₋M + ½Xₖ₊M
Trap: Demodulator: linear, NOT time-invariant.
Read Xₖ off Euler: cos θ = ½ejθ + ½e−jθ
Trap: No integral needed if x is a sum of harmonics.
H(kω₀) = 0 at some k ⇒ input not unique from output
Trap: Add a cosine at that frequency to x (2024 Q4d).
Differential eq. from H(ω): cross-multiply, jω → d/dt, (jω)² = −ω² → d²/dt²
Needs: State "initial rest".
Trap: 2024 Q4a: y″ + a y′ + y = x + x″/(4π²).
Past paper: 2022 Q3: x = 1−t² on |t|≤1, T₀=2 ⇒ X₀ = 2/3; with H(0)=1/4 ⇒ Y₀ = 1/6. 2024 Q4: X₀=β, H(0)=1, Y₀=1/4 ⇒ β=1/4.
Past paper: Sample Q8: bandpass passes only ω = ±1. T=2π ⇒ k=±1 ⇒ y = (2/π)sin(π/5)cos t. T=4π ⇒ k=±2 ⇒ y = (1/π)sin(2π/5)cos t. T=8π ⇒ several k ⇒ not one cosine.
Past paper: Mock Q4: Wₖ = ½Xₖ₋₁+½Xₖ₊₁, Y₀ = A·W₀ = A(0.25+0.25) = 2 ⇒ A = 4, any 0 < B < ω_c.

7Frequency response2022 Q4, sample Q6, mock Q6

x = ejωt ⇒ y = H(ω)ejωt. x = cos(ωt+φ) ⇒ y = |H(ω)|cos(ωt+φ+∠H(ω))
Needs: Real, stable LTI. Eternal input.
Trap: Frequency never changes. y = H(ω)x is wrong for general x.
Constant input a ⇒ y = a·H(0)
Needs: a = a·ej0t.
Output sinusoid given, find input: divide each phasor by H(ω₀)
Trap: Do each frequency separately.
From ODE: Σaₖ(jω)ᵏY = Σbₖ(jω)ᵏX. From difference eq: Σaₖe−jωkY = Σbₖe−jωkX
Trap: RC: H = 1/(1+jωRC).
Delay τ: e−jωτ. Gain 0.5 + delay 0.1: h = 0.5δ(t−0.1), H = 0.5e−0.1jω
Trap: Undo it: z(t) = 2y(t+0.1).
Ideal LPF |ω|<W: h = sin(Wt)/(πt)
Trap: Non-causal. sin(Wt)/(πt) has cutoff W rad/s.
H = Y/X fails where X = 0
Trap: That is 0/0, not H = 0.
Past paper: Sample Q6: H = Y/X = ejω(jω+1)/(jω+a); input a ⇒ y = a·H(0) = 1.

9Sampling, aliasing, reconstruction2022 Q6, 2024 Q6, mock Q8, sample Q1, Q10

No aliasing iff Ts < π/W (ω_s > 2W, fs > 2f_max)
Needs: W = highest frequency in rad/s.
Trap: Bandpass 5π–8π: W = 8π ⇒ Nyquist rate 16π rad/s = 8 samples/s.
Nyquist rate = 2W (a rate). Nyquist frequency = π/Ts
Trap: Never sample a sinusoid at exactly Ts = π/ω₀.
Anti-aliasing LPF cutoff ≤ π fs rad/s (= fs/2 Hz)
Needs: Filter BEFORE sampling.
Trap: Sample Q1: sin(Wt)/(πt) has cutoff W ⇒ largest W = π fs.
Xs(ω) = (1/Ts)Σ X((ω−2πℓ)/Ts); inside the band X(ω) = Ts Xs(Ts ω)
Trap: Mock Q8: peak 20 → 2, edge 2π/3 → 20π/3 rad/s.
Impulse train p = Σδ(t−nT): Z(ω) = (1/T)Σ X(ω−2πk/T)
Needs: Copies every 2π/T rad/s.
Trap: Recover with a filter of gain T on the band (2024 Q6: H₂ = 1/4 for 5π<|ω|<8π).
Hz to rad/sample: ω = 2πf/fs
Needs: DT filter design.
Trap: 50 Hz at fs=500 ⇒ π/5. Sketch DT filters over −2π..2π (they repeat).
Energy of xs: Σ|xs|² = (1/2π)∫−ππ|Xs|²dω
Needs: Use evenness: (1/π)∫₀^π.
Trap: Mock Q8: 800/9.
Ideal reconstruction: H = Ts on |ω|<π/Ts; h = sinc, non-causal. ZOH delay ≈ Ts/2
Needs: Interpolation needs h(nTs) = δ[n].

Trap: Marks are for this sentence.

10Laplace: H(s), RoC, stability, output2022 Q7, 2024 Q8, mock Q5, Q7, sample Q3, Q5

Trap: Poles −1, −2 ⇒ a=3, b=2.

11Z-transform: H(z), poles, stability2022 Q8, 2024 Q2–3, Q5, mock Q9, sample Q7

Difference eq. → Ĥ: x[n−m] → z−mX̂, solve Ŷ/X̂
Trap: Then multiply top and bottom by z² to match a requested form.
Poles: roots of the denominator in z. Polar form rejθ
Trap: z²+z+1 = 0 ⇒ e±j2π/3 (on the unit circle).
Causal ⇒ |z| > outermost pole. Stable ⇔ unit circle in the RoC
Needs: Independent checks. FIR: poles only at 0 (always stable); IIR: any other pole.
Trap: Pole on |z|=1 ⇒ not stable. Step response: Ĥ(z)/(1−z⁻¹).
Inverse: match a table row, or partial fractions on Ŷ/z, then multiply by z
Trap: αⁿcos(ω₀n)u[n] row: numerator 1−αz⁻¹cos ω₀.
Unstable ⇒ give a bounded input at the pole frequency (resonance)
Trap: x = cos(2πn/3) into poles e±j2π/3 ⇒ y grows.
Ĥ → difference equation: cross-multiply, z−m → delay m
Needs: Say "subject to initial rest".
Trap: Forgetting initial rest loses a mark.
x[n+1] in the equation ⇒ positive power of z in the numerator
Trap: 2022 Q8: Ĥ = z(2z+1)/(z+2), pole −2 ⇒ not stable.
Past paper: 2024 Q3: ½+z⁻¹−z⁻² over 1+2z⁻¹+z⁻² = (z²+2z−2)/(2z²+4z+2) ⇒ a=2, b=−2, c=2, d=4, e=2. Causal and LTI (initial rest).
Past paper: 2024 Q5: (1+0.5z⁻¹)/(1+z⁻¹+z⁻²): poles e±j2π/3, RoC |z|>1, h = cos(2πn/3)u[n] (α=1, cos ω₀ = −½), not stable.
Past paper: Mock Q9: x=0.5ⁿu, y=0.25ⁿu ⇒ Ĥ=(1−0.5z⁻¹)/(1−0.25z⁻¹), IIR, h = 2δ[n] − 0.25ⁿu[n]. Sample Q7: step of 1/(1+z⁻¹+z⁻²) has Z-transform 1/(1−z⁻³), |z|>1.
