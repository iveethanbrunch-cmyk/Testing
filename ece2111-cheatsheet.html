System classification

Use when: Seen: 2022 Q2, 2024 Q1, mid-sem Q1, sample and mock.
Formula / fact
Conditions needed
Trap
Memoryless? Only the current input appears, with the same time index
Trapx(t+2), x[n−1], sums over k all have memory.
Causal? Any input at a later time than the output?
NeedsMemoryless ⇒ causal.
TrapΣ over k=−1..1 of x[n−k] uses x[n+1], so non-causal. e−tx(t+2) is non-causal.
Linear? Check x→0 gives 0, then scaling and addition
NeedsA fixed multiplier of the signal is fine (e−t, sin t, n²).
TrapSquaring x, adding a constant, or |x| all break linearity. Initial rest keeps y=x+0.5x(t−1) linear.
Time-invariant? Does any coefficient depend on t or n?
NeedsTime-varying multiplier ⇒ TV.
Trape−tx(t+2) is TV. 2ejω₁tx(t−1) is TV. x[n−1]²+x[n] is TI but non-linear.
BIBO stable? Bound |y| using |x| ≤ M
NeedsFinite sum of delayed copies ⇒ stable.
TrapComplex exponential multipliers have magnitude 1, so they stay stable.
Real system? Real input must always give real output
NeedsComplex coefficients or ejωt multipliers ⇒ not real.
Trap2024 Q1: y = 2ejω₁tx(t−1)+ejω₂tx(t−2) is linear, TV, causal, has memory, stable, NOT real.
"Is it LTI?" for a system that creates new frequencies
NeedsAn LTI system only scales and phase-shifts each input frequency.
TrapMock Q6d: 440 Hz tone in, 330 and 550 Hz out ⇒ not LTI.

Stuck? Try: Write y for x=0, for 2x, and for x₁+x₂, then for a delayed x. Four lines, four answers.

Periodicity

Use when: "Is it periodic? Find the fundamental period."
Formula / fact
Conditions needed
Trap

NeedsAlways periodic for ω₀≠0.

The five property tests

Use when: Classify a system. Do each test separately.
Formula / fact
Conditions needed
Trap
Memoryless: y(t)=F(t,x(t))
NeedsOutput at t uses only x at t.
TrapDelay, advance, integrator and differentiator all have memory.
Causal: no future input
NeedsMemoryless systems are causal. Check y at one time.
Trapy(t)=x(2t) is non-causal (y(1)=x(2)). A predictor built from past data is causal.
