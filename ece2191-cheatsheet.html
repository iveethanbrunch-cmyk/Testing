Topics

W1

Probability, random variables, expectation

Use when: Any "find the probability" or "find the mean" question.
Formula / fact
Conditions needed
Trap
Ω → event → X → PMF → E[X] → Var(X)
NeedsWrite Ω first, then the event as a subset.
TrapX=1 for "error" is not the transmitted bit.
E[X] = Σ x P(X=x)
NeedsPMF sums to 1.
TrapPair each probability with its own x.
Var(X) = E[X²] − (E[X])², SD = √Var
E[aX+b] = aE[X]+b, Var(aX+b) = a²Var(X)
TrapThe shift b drops out of the variance.
W1

Bernoulli, Binomial, Geometric

Use when: Counting successes or waiting for the first one.
Formula / fact
Conditions needed
Trap
Bernoulli(p): P(1)=p. E=p, Var=p(1−p)
NeedsOne yes/no trial.
TrapVar is largest at p=½.
Binomial(n,p): P(X=k) = C(n,k) pᵏ (1−p)ⁿ⁻ᵏ. E=np, Var=np(1−p)
Needsn fixed, independent trials, same p.
TrapP(at least one) = 1 − (1−p)ⁿ. E[X]=1 does not mean P(X≥1)=1.
Geometric(p): P(X=k) = (1−p)ᵏ⁻¹ p, k=1,2,... E=1/p, Var=(1−p)/p²
NeedsCounts trials including the first success.
TrapBinomial: fixed n. Geometric: stop at first success.
Memoryless: P(X>m+n | X>m) = P(X>n)
NeedsGeometric only (discrete).
TrapP(X>n) = (1−p)ⁿ.
W1

Conditional, joint, independence

Use when: Event trees, tables of P(X,Y).
Formula / fact
Conditions needed
Trap
P(A|B) = P(A,B)/P(B)
NeedsP(B)>0.
TrapP(A|B) ≠ P(B|A).
P(A,B) = P(A|B)P(B) = P(B|A)P(A)
NeedsMultiply along branches of an event tree.
Total probability: P(A) = P(A|B)P(B) + P(A|Bᶜ)P(Bᶜ)
TrapDenominator of Bayes sums over every branch.
Bayes: P(B|A) = P(A|B)P(B)/P(A)
Marginal: P(X=x) = Σ_y P(X=x,Y=y)
Independent ⇔ P(x,y) = P(x)P(y) for ALL cells
NeedsCheck every cell.
TrapOne mismatch settles it. One match proves nothing.
W1

Covariance, correlation, E[XY]

Use when: Two random variables together.
Formula / fact
Conditions needed
Trap
E[XY] = Σ_x Σ_y xy P(x,y)
E[X+Y] = E[X]+E[Y]
NeedsAlways. No independence needed.
Var(X+Y) = Var X + Var Y + 2Cov(X,Y)
NeedsIf independent, Cov=0.
TrapVariance adds only for uncorrelated variables.
Cov(X,Y) = E[XY] − E[X]E[Y]
ρ = Cov(X,Y)/√(Var X Var Y), −1 ≤ ρ ≤ 1
Independent ⇒ Cov=0. Cov=0 does NOT imply independent
TrapOrthogonal means E[XY]=0. Uncorrelated means Cov=0.
Model assumptions: independence, constant p, identically distributed, no memory
NeedsBursts, fading, drift, wear break them.
TrapSimple models underestimate rare extreme events.
W2

PDF and CDF

Use when: Continuous random variable questions.
Formula / fact
Conditions needed
Trap
P(a ≤ X ≤ b) = ∫ f(x)dx from a to b
Needsf ≥ 0 and total area 1.
TrapP(X = x) = 0 for any single x.
F(x) = P(X ≤ x) = ∫ f from −∞ to x. f(x) = dF/dx
P(a<X≤b) = F(b) − F(a)
F is non-decreasing, F(−∞)=0, F(∞)=1
TrapA PDF can exceed 1. A probability cannot.
E[X] = ∫ x f(x)dx. E[g(X)] = ∫ g(x) f(x)dx
Var(X) = E[X²] − (E[X])²

Stuck? Try: Convert the question to an interval, then use the CDF.

W2

Uniform, Exponential, Gaussian

Use when: Pick the model from the story.
Formula / fact
Conditions needed
Trap
Uniform(a,b): f = 1/(b−a). F = (x−a)/(b−a) on [a,b]. E = (a+b)/2, Var = (b−a)²/12
Needsa ≤ x ≤ b.
TrapHeight is forced by area 1.
Exponential(λ): f = λe−λx, x≥0. F = 1 − e−λx. E = 1/λ, Var = 1/λ²
Needsλ is a rate (events per unit time).
TrapP(X>x) = e−λx. Models only the constant-failure-rate phase.
Exponential is memoryless: P(X>s+t | X>s) = P(X>t)
NeedsContinuous analogue of geometric.
Gaussian N(μ,σ²): f = (1/(σ√2π)) e−(x−μ)²/2σ²
NeedsMany small independent effects.
TrapNo closed-form CDF. Standardise.
Empirical rule: μ±σ ≈ 68.27%, μ±2σ ≈ 95.45%, μ±3σ ≈ 99.73%
NeedsGaussian only.
W2

Joint, marginal and conditional PDFs

Use when: Two continuous variables.
Formula / fact
Conditions needed
Trap
P((X,Y) in region R) = ∬ f(x,y) dx dy over R
Needsf ≥ 0 and total volume 1.
TrapDraw the region first, then set the limits.
Marginal: fX(x) = ∫ f(x,y)dy
TrapLimits can depend on x.
Conditional: f(x|y) = f(x,y)/fY(y)
NeedsfY(y)>0.
Independent ⇔ f(x,y) = fX(x)fY(y) for all x,y
NeedsFactorises, including the support.
TrapZero covariance alone is not enough.
E[g(X,Y)] = ∬ g f dx dy. Cov = E[XY] − E[X]E[Y]
W3

Sums and sample mean

Use when: Total or average of n readings.
Formula / fact
Conditions needed
Trap
Sn = ΣXᵢ. E[Sn] = ΣE[Xᵢ]
NeedsAlways.
Var(Sn) = ΣVar(Xᵢ) + ΣΣi≠j Cov(Xᵢ,Xⱼ)
NeedsIndependent: just ΣVar(Xᵢ).
TrapVariance does not add automatically.
X̄_n = Sn/n. E[X̄_n] = μ
NeedsEqual means.
Var(X̄_n) = σ²/n, SD = σ/√n
NeedsIID (independent and identically distributed).
TrapAveraging shrinks the estimator spread, not a single measurement.
Var(cX) = c²Var(X)
W3

Law of Large Numbers and Central Limit Theorem

Use when: Convergence versus shape of the distribution.
Formula / fact
Conditions needed
Trap
LLN: X̄_n → μ as n grows
NeedsIID, finite mean and variance.
TrapSays where, not how it is spread.
CLT: Zn = (X̄_n − μ)/(σ/√n) → N(0,1)
NeedsIID, finite mean and variance.
TrapFails with burst errors or drift (independence or identical distribution broken).
X̄_n ≈ N(μ, σ²/n). Sn ≈ N(nμ, nσ²)
Needsn large. Rule of thumb n ≥ 30.
TrapSkewed or multimodal parents need larger n.
LLN: point. CLT: shape.
W3

Standardising Gaussians, Φ and Q

Use when: Any P(X ≤ x) for a Gaussian.
Formula / fact
Conditions needed
Trap
Z = (X−μ)/σ ~ N(0,1)
TrapSubtract mean, divide by SD (not variance).
P(X ≤ x) = Φ((x−μ)/σ)
TrapCheck whether the Z-table is lower-tail or upper-tail.
P(a<X<b) = Φ((b−μ)/σ) − Φ((a−μ)/σ)
Q(z) = P(Z>z) = 1 − Φ(z). Φ(−z) = 1 − Φ(z)
NeedsQ is the comms convention for tail probability.
Φ(1.5) = 0.9332. Φ(1)=0.8413. Φ(1.96)=0.975

Stuck? Try: Standardise first. Sketch the bell and shade the area to decide Φ or 1−Φ.

W4

Point estimates and standard error

Use when: Estimate parameters from data.
Formula / fact
Conditions needed
Trap
μ̂ = x̄ = (1/n)Σxᵢ
σ̂² = s² = (1/(n−1)) Σ(xᵢ−x̄)²
NeedsPopulation mean unknown, replaced by x̄.
TrapDivide by n−1, not n.
Fit a PMF: p̂ = successes / trials. Fit a PDF: use μ̂, σ̂²
TrapThen compute probabilities from the fitted model.
SE(X̄) = σ/√n (or s/√n if σ unknown)
TrapMore data shrinks SE, not the spread of one reading.
Unbiased: E[θ̂]=θ. Consistent: θ̂ → θ as n grows
TrapThey are different properties.
W4

Confidence intervals

Use when: "Give a 95% interval", "plus or minus".
Formula / fact
Conditions needed
Trap
x̄ ± zα/2 σ/√n
NeedsIID, σ known, population Gaussian or n large (CLT).
TrapIf σ is unknown the course flags Student t (beyond scope).
90%: z = 1.645. 95%: z = 1.96. 99%: z = 2.576
Higher confidence ⇒ wider. Larger n ⇒ narrower.
TrapPrecision and coverage trade off.
Meaning: 95% of intervals built this way contain μ
NeedsRepeated sampling.
TrapIt is not "95% probability μ is in this interval".
Total (sum) question: Sn ≈ N(nμ, nσ²)
TrapDo not use the sample-mean form for a total.
Significance level = 100% − confidence level
W4

Margin of error and sample size

Use when: "How many measurements?"
Formula / fact
Conditions needed
Trap
MOE = zα/2 σ/√n
n = (zα/2 σ / MOE_max)²
Needsσ known.
TrapALWAYS round up. Example: 61.47 → 62.
n ∝ 1/MOE²
TrapHalving MOE needs 4× the data.
Typical confidence: 90% exploratory, 95% default, 99% safety-critical
W5

Vector random variables

Use when: X = [X₁,...,Xn]ᵀ, covariance matrices.
Formula / fact
Conditions needed
Trap
Mean vector μ = E[X]
Correlation matrix R_XX = E[XXᵀ]
NeedsSecond moments.
TrapOff-diagonals need not vanish under independence.
Covariance matrix C_XX = E[(X−μ)(X−μ)ᵀ]
NeedsDiagonal = variances, off-diagonal = covariances.
C_XX = R_XX − μμᵀ
TrapConvert instead of recomputing every entry.
C_XX is symmetric and positive semidefinite
Gaussian vector: f(x) = (1/((2π)n/2|C|1/2)) exp(−½ (x−μ)ᵀC⁻¹(x−μ))
NeedsC nonsingular.
TrapCheck |C| ≠ 0 first.
Jointly Gaussian and Cov=0 ⇒ independent
NeedsBoth conditions.
TrapZero covariance alone does not give independence.
Contours: variances set spread along axes; covariance sets tilt
TrapOne state variable's uncertainty is the matching diagonal entry of C.
W7

Univariate linear regression

Use when: Fit ŷ = wx + b to data.
Formula / fact
Conditions needed
Trap
Zero-order model: ŷ = b = ȳ
TrapBaseline. Good only if x and y are unrelated.
Loss (MSE): L = (1/m)Σ(yᵢ − wxᵢ − b)²
NeedsConvex: unique global minimum.
Set ∂L/∂w = 0 and ∂L/∂b = 0 (Fermat)
TrapStationary point alone is not enough in general; convexity here guarantees a minimum.
w* = σ̂ₓᵧ / σ̂ₓₓ, b* = ȳ − x̄w*
Needsσ̂ₓᵧ = (1/m)Σ(xᵢ−x̄)(yᵢ−ȳ), σ̂ₓₓ = (1/m)Σ(xᵢ−x̄)²
TrapDivide by m, not m−1.
w = (Σxᵢyᵢ − m x̄ȳ)/(Σxᵢ² − m x̄²), b = (ȳΣxᵢ² − x̄Σxᵢyᵢ)/(Σxᵢ² − m x̄²)
NeedsUse when you are given raw sums.
Supervised learning: data (xᵢ,yᵢ). Regression predicts a number, classification a label
sklearn: LinearRegression().fit(X.reshape(-1,1), y); coef_, intercept_
TrapX must be a column matrix (m,1).
W8

Multivariate linear regression

Use when: Several inputs, matrix form.
Formula / fact
Conditions needed
Trap
ŷ = wᵀx. X is m×n (one sample per row), y is m×1
w* = X⁺y
NeedsX full rank.
m ≥ n (tall): X⁺ = (XᵀX)⁻¹Xᵀ. m < n (fat): X⁺ = Xᵀ(XXᵀ)⁻¹
TrapFat case: infinitely many exact fits; X⁺ gives the minimum-norm one.
Bias: append a column of 1s to X; w₀ is the bias
TrapWithout it the plane passes through the origin (MSE can be much worse).
Multiple outputs: ŷ = Wᵀx, W* = X⁺Y (Y is m×p)
TrapCompute X⁺ once for all outputs.
R² = 1 − Σ(yᵢ−ŷᵢ)² / Σ(yᵢ−ȳ)²
TrapR²=1 perfect, R²=0 same as the zero-order baseline.
numpy: w = np.linalg.pinv(np.c_[np.ones(m), X]) @ y
W9

Polynomial regression and overfitting

Use when: Nonlinear data, choosing the degree.
Formula / fact
Conditions needed
Trap
ŷ = w₀ + w₁x + ... + w_Kx^K (Maclaurin truncation)
NeedsLinear in w. Same pseudo-inverse solution.
TrapK is a hyperparameter.
Features of degree ≤ k from n inputs: C(n+k, k)
TrapIncludes cross terms, e.g. x₁x₂, x₁x₂². The count explodes (n=100, k=5: 96.5 million).
Rule of thumb: at least 10 samples per parameter
Training error falls as degree rises. Test error falls then rises
TrapUnderfit: both high. Overfit: train low, test high.
BIC = d·ln(m) + m·ln(MSE)
Needsd = number of parameters, m = samples, MSE on training data. ln is natural log.
TrapBIC can be negative. Pick the degree with the minimum BIC.
sklearn: PolynomialFeatures(degree) in a pipeline with LinearRegression
W10

Gradient descent

Use when: No closed form, or "do two iterations".
Formula / fact
Conditions needed
Trap
w⁽ᵏ⁾ = w⁽ᵏ⁻¹⁾ − η ∇f(w⁽ᵏ⁻¹⁾)
Needsη>0 learning rate, f differentiable.
TrapUpdate every coordinate with the OLD point, simultaneously.
∇f = [∂f/∂x₁, ..., ∂f/∂xn]ᵀ points to steepest ascent
TrapDescent uses the negative gradient. Gradient is perpendicular to level sets.
η too small: slow. Moderately large: bounces and plateaus. Too large: diverges
Stop when ‖∇f‖ ≤ ε, or f decrease ≤ ε, or ‖w⁽ᵏ⁾−w⁽ᵏ⁻¹⁾‖ ≤ ε, or k = max
Convex loss: reaches the global minimum. Non-convex (neural nets): a good minimum
Direction-by-direction search needs 2ⁿ checks
TrapDoes not scale. That is why the gradient is used.
Chain rule: y = θ₃ + b, θ₃ = w₂θ₂, θ₂ = φ(θ₁), θ₁ = w₁x
Needsdy/dw₁ = w₂ φ′(θ₁) x
TrapBackpropagation is repeated chain rule.

Stuck? Try: Quadratic 1-D: ∇f = f′, update ω ← ω − ηf′(ω). Example f=ω²+5ω+6, ω₀=2, η=0.1 → 1.1.

W11

Logistic regression

Use when: Two-class prediction.
Formula / fact
Conditions needed
Trap
σ(z) = 1/(1+e−z), σ(0)=0.5, σ′ = σ(1−σ)
Needs0 < σ < 1.
TrapSaturates for |z| > 6 (tiny gradient).
ŷ = σ(wᵀx). Predict class 1 if ŷ ≥ 0.5
NeedsBias via x[0]=1.
TrapThe decision boundary is a line or hyperplane.
BCE per sample: ℓ = −[y ln ŷ + (1−y) ln(1−ŷ)]
NeedsNatural log.
TrapDo not use MSE with a sigmoid (vanishing gradient, wrong likelihood).
∇_w L = (1/m) Σ (ŷᵢ − yᵢ) xᵢ
TrapNo closed form. Train by gradient descent. BCE is convex.
Why linear regression fails: unbounded output, wrong objective, outliers skew the line
W11

Softmax classifier

Use when: More than two classes.
Formula / fact
Conditions needed
Trap
pr = ezr / Σ ezi
TrapProbabilities sum to 1. Order of logits preserved.
z = Wᵀx, W is n×K (one column per class)
NeedsLabels one-hot, not 1,2,3.
TrapInteger labels imply a false ordering.
Loss: L = −Σ yr ln ŷ_r = −ln ŷ_c
Needsc = true class.
∇_W L = (1/m) Σ xᵢ(ŷᵢ − yᵢ)ᵀ
Example: z=(5.2, 3.6, −2.7) → p ≈ (0.832, 0.168, 0.0003)
W11

Confusion matrix and metrics

Use when: Evaluate a classifier.
Formula / fact
Conditions needed
Trap
Rows = true class, columns = predicted. Diagonal = correct
Accuracy = (TP+TN)/N
TrapMisleading with imbalanced classes: always guessing the majority scores high.
Precision = TP/(TP+FP). Recall = TP/(TP+FN)
TrapMiss = FN. False alarm = FP.
F₁ = 2·P·R/(P+R)
NeedsHarmonic mean.
TP=6, FP=2, FN=3 → P=0.75, R≈0.67, F₁≈0.71
Imbalance fixes: class weights, resampling. predict_proba lets you change the 0.5 threshold
W12

Ridge (L2) regression

Use when: Overfitting, many parameters, regularisation.
Formula / fact
Conditions needed
Trap
L_ridge = (1/m)Σ(ŷᵢ−yᵢ)² + α‖w‖²
Needsα ≥ 0 hyperparameter.
Trapα=0 gives ordinary least squares. Larger α shrinks w toward 0.
w* = (XᵀX + αI)⁻¹ Xᵀy
NeedsStill has a closed form.
TrapAdds α to the diagonal of XᵀX.
Occam: prefer the simpler model that fits equally well
sklearn: Ridge(alpha=1.0)
NeedsTune α.
W12

Neurons and shallow neural networks

Use when: Forward pass by hand, counting parameters.
Formula / fact
Conditions needed
Trap
Neuron: output = φ(wᵀx). φ = σ gives logistic regression
Hidden layer: h = φ(W₁ᵀx). Output: y = W₂ᵀh
NeedsW₁ is n×H, W₂ is H×p. Bias via a 1 appended.
TrapApply φ elementwise.
ReLU: max(0,a). Sigmoid: 1/(1+e−x). tanh: (eˣ−e⁻ˣ)/(eˣ+e⁻ˣ)
NeedsReLU range [0,∞). Sigmoid (0,1). tanh (−1,1).
TrapReLU can die (stuck at 0).
Classification head: softmax(W₂ᵀh), cross-entropy. Regression: MSE
TrapPre-softmax values are logits.
Parameters ≈ n·H + H·p (plus biases)
TrapExample: 100·500 + 500·1 = 50,500.
Universal approximation: one hidden layer, enough neurons, continuous f
TrapMore hidden units = more piecewise-linear joints.
Training: backpropagation = chain rule + gradient descent

Stuck? Try: Forward pass: multiply, apply ReLU (negative → 0), multiply again. Example gave y = 3.
