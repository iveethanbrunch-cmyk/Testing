1How to score, and what is handed to you

Read once before you start.

Trap: "No marks if no reasoning." Text boxes: a/b, a^(b), C(n,r), sqrt(), Phi(x).

3Probability rules and countingpractice 2 Q6, 3 Q3, 4 Q1, Q6

P(A|B) = P(A∩B)/P(B). P(A∩B) = P(A|B)P(B)
Trap: P(A|B) ≠ P(B|A).
Total: P(A) = Σ P(A|Bᵢ)P(Bᵢ). Bayes: P(Bᵢ|A) = P(A|Bᵢ)P(Bᵢ)/P(A)
Needs: Bᵢ partition the space.
Trap: Draw the tree. Leaves sum to 1.
Independent ⇔ P(A∩B) = P(A)P(B)
C(n,k) = n!/(k!(n−k)!). Arrangements in a line n!. Round table (n−1)!
Hypergeometric: P(j special in k drawn from N with M special) = C(M,j)C(N−M,k−j)/C(N,k)
Needs: No replacement.
Groups by category: Π C(category size, chosen) / C(total, group size)
Trap: Chosen counts must add to the group size.
Past paper: Spouse next to me at a 20-seat round table: 2·18!/19! = 2/19. Exactly 1 of 5 chips faulty (11 of 30 broken): C(11,1)C(19,4)/C(30,5) = 0.2992.
Past paper: P(not faulty) = 0.8(5/30)+0.6(25/30) = 0.6333; P(new | not faulty) = 0.1333/0.6333 = 0.2105.

4Discrete distributionspractice 2 Q1, 3 Q2, 4 Q4, mid-sem Q1–2

Bernoulli(p): E = p, Var = p(1−p)
Binomial(n,p): P(k) = C(n,k)pᵏ(1−p)ⁿ⁻ᵏ, E = np, Var = np(1−p)
Needs: Fixed n, independent, same p.
Trap: P(at least one) = 1−(1−p)ⁿ. Bursty errors ⇒ not binomial, but E[S] = np still holds.
Geometric(p): P(k) = (1−p)ᵏ⁻¹p, k ≥ 1. P(X>k) = (1−p)ᵏ. E = 1/p, Var = (1−p)/p²
Needs: Trials up to and including first success.
Trap: Memoryless: 5 failures done, P(more than 3 more) = 0.8³.
Poisson(λ): P(k) = e−λλᵏ/k!, E = Var = λ
Needs: λ = rate × interval (same units).
Trap: Scale λ first: 600/min over 200 ms ⇒ λ = 2. 1460/yr over a day ⇒ λ = 4.
P(N=0) = e−λ. P(N ≤ 2) = e−λ(1+λ+λ²/2)
Trap: λ=2: 0.1353, 0.6767. λ=4: 0.0183, 0.2381.
E[X] = Σx p(x). Var = E[X²] − (E[X])²
Needs: PMF sums to 1.
Y = g(X) discrete: P(Y=y) = sum of P over the x values (or regions) that map to y
Past paper: Frisbee (p=0.1): P(X=k)=0.9ᵏ⁻¹(0.1); P(X>3)=0.9³=0.729; E=10. Meatballs in 100 throws: Binomial(100, 0.1).

5Continuous: PDF, CDF, unknown constantpractice 2 Q3, 3 Q4, 4 Q2, mid-sem Q4–5, Q13–14

∫f = 1 fixes the constant. A second fact (e.g. E[X]) fixes a second constant
F(x) = ∫ from the lower end to x of f. Write 0 below and 1 above
Needs: Piecewise answer.
Trap: P(X = x) = 0 for continuous X.
P(a<X<b) = F(b)−F(a). E[X] = ∫xf. E[X²] = ∫x²f
Trap: Symmetric f ⇒ E = centre, P(X ≥ centre) = ½.
Y = aX+b: E = aE[X]+b, Var = a²Var(X)
Trap: °F = 1.8°C+32 ⇒ VarF = 3.24 VarC. Y = 2X+1 ⇒ Var ×4.
Uniform(a,b): f = 1/(b−a), E = (a+b)/2, Var = (b−a)²/12
Exponential(λ): f = λe−λx, F = 1−e−λx, P(X>x) = e−λx, E = 1/λ, Var = 1/λ²
Needs: Constant failure rate.
Trap: Mean 200 h ⇒ λ = 0.005, Var = 40,000, SD = 200. "Most fail near 200 h" is FALSE: density is largest at 0.
Gaussian N(μ,σ²): f = e−(x−μ)²/2σ²/(σ√2π), peak 1/(σ√2π)
Trap: Higher peak ⇒ smaller σ. f(0) is not a probability.
Flat CDF on an interval ⇒ zero probability there
Trap: Not uniform.
Past paper: f = a(4−(x−38)²) on [36,40] ⇒ a = 3/32, E = 38, P(X ≥ 38) = ½. f = ax^b on [0,1], E=0.6 ⇒ a=1.5, b=0.5, F = x1.5, Var = 3/7−0.36 = 0.0686, P(X>0.5) = 0.646.

6Joint distributions, covariance, vectorspractice 3 Q5, 4 Q5–6, mid-sem Q3, Q15

Marginal: pX(x) = Σ_y p(x,y), fX(x) = ∫f(x,y)dy
Trap: Limits for y may depend on x.
Conditional: f(y|x) = f(x,y)/fX(x)
Trap: f=2 on 0<y<x<1 ⇒ fX=2x, f(y|x)=1/x, P(Y<x/2 | X=x) = ½.
Independent ⇔ p(x,y) = pX(x)pY(y) for EVERY cell (support must be a rectangle)
Trap: One failing cell proves dependence.
Cov = E[XY] − E[X]E[Y]. ρ = Cov/(σ_Xσ_Y) ∈ [−1,1]
Trap: Cov = 0 ⇒ uncorrelated, NOT independent (X on {−1,0,1}, Y = X²).
E[aX+bY] = aE[X]+bE[Y] (always). Var(X+Y) = VarX + VarY + 2Cov
Trap: Cov(F, aF+b) = a Var(F).
Vector: C = E[(X−μ)(X−μ)ᵀ] = R − μμᵀ, symmetric PSD
Needs: Diagonal = variances.
Jointly Gaussian and Cov = 0 ⇒ independent
Needs: Both needed.
Past paper: p(0,1)=p(1,0)=p(2,1)=1/3: E[X]=1, E[Y]=2/3, E[XY]=2/3 ⇒ Cov = 0, uncorrelated. P(0,0)=0 ≠ (1/3)(1/3) ⇒ dependent.
Past paper: 3 balls from 2R,3W,4B: p(x,y) = C(2,x)C(3,y)C(4,3−x−y)/C(9,3).

7Gaussians, sample means, LLN, CLTpractice 2 Q2, 3 Q1, Q6, 4 Q7, mid-sem Q6–8

Z = (X−μ)/σ. P(X ≤ x) = Φ(z). P(X > x) = 1−Φ(z)
Trap: Divide by σ, not σ².
X̄ ~ N(μ, σ²/n): use SE = σ/√n. Sum Sn ~ N(nμ, nσ²)
Needs: Gaussian data, or CLT for large n.
Trap: A total uses the sum form.
CLT: IID, finite mean and variance; n ≥ 30 is a rule of thumb
Trap: Rare events (p = 0.001, n=30): P(X̄=0) = 0.97 ⇒ not Gaussian.
LLN: X̄ → μ (where). CLT: shape around μ
Needs: IID needed.
Trap: Drift or bursts break IID: more data does not fix it.
Symmetric interval with prob p: μ ± z·σ/√n with Φ(z) = (1+p)/2
Trap: 95% ⇒ 1.96. 60% ⇒ Φ(z)=0.8 ⇒ z = 0.84.
Past paper: Sources above 240: A (230,5) z=2 ⇒ 0.0228; B (225,10) z=1.5 ⇒ 0.0668 ⇒ B more likely. Sensor lifetimes ≥30,000: S1 0.0228, S2 0.0668 ⇒ choose S2.
Past paper: Mid-sem Q8: (13.2−12)/(6/√64)=1.6 ⇒ 1−0.9452=0.0548. Chef: σ=10, n=16 ⇒ SE 2.5; P(45<X̄<52)=Φ(2.8)−0.5=0.4974; 95% of means in 45±4.9.

8Estimation, confidence intervals, sample sizepractice 2 Q4–5, mid-sem Q9–12

x̄ estimates μ. s² = Σ(xᵢ−x̄)²/(n−1)
Trap: Divide by n−1.
Unbiased: E[θ̂] = θ. Consistent: θ̂ → θ as n grows
Trap: X₁ and X̄ are both unbiased; X̄ has the smaller SE.
CI: x̄ ± zα/2·σ/√n
Needs: IID, σ known, Gaussian or large n.
Trap: σ unknown and replaced by s ⇒ Student t, not exact with z.
Meaning: 95% of intervals built this way contain μ
Trap: Not "95% of items" and not "μ has 95% probability".
CI fully inside a tolerance ⇒ supports "mean is within tolerance"
Higher confidence ⇒ wider. Larger n ⇒ narrower
n = (z σ / E)², ALWAYS round up
Needs: E = maximum margin of error.
Trap: Halve E ⇒ 4× n.
Past paper: P(|X̄−μ| < σ/10) ≥ 0.95 ⇒ 1.96σ/√n ≤ σ/10 ⇒ n ≥ 384.16 ⇒ n = 385.

9Binary detection in Gaussian noisepractice 4 Q3, practice 5

Decide "0" (X=−1) if f(y|−1)P₀ > f(y|+1)P₁
Needs: Y = X + N, N ~ N(0,σ²).
Threshold T = (σ²/2) ln(P₀/P₁): decide 0 if y < T
Needs: Equal noise, levels ±1.
Trap: Equal priors ⇒ T = 0.
P(error) = P₀·Q((T+1)/σ) + P₁·Q((1−T)/σ)
Trap: Q = 1−Φ.
Past paper: P₀ = 2P₁, σ² = 1/16: T = ln2/32 = 0.0217; P(error) ≈ 3.0×10⁻⁵.

10Regressionpractice 5, 6 Q1–11

Univariate: w = σ̂ₓᵧ/σ̂ₓₓ, b = ȳ − w x̄ (or w = (Σxy − m x̄ȳ)/(Σx² − m x̄²))
Needs: Divide by m in σ̂.
Least squares with bias ⇒ Σeᵢ = 0, Σxᵢeᵢ = 0, Σŷᵢeᵢ = 0
Needs: eᵢ = yᵢ − ŷᵢ.
Trap: Use these to recover lost residuals.
MSE = (1/m)Σeᵢ². R² = 1 − SSE/SST (fraction of variance explained)
Trap: Higher R² is better on training data, but always grows with more features.
Tall X (m ≥ n): W = (XᵀX)⁻¹XᵀY. Fat X: w = Xᵀ(XXᵀ)⁻¹y (minimum norm)
Needs: Add a column of 1s for the bias.
Trap: Fat: infinitely many zero-error fits; zero training error means little.
Linear in parameters ⇒ still linear regression (x², cos x, sin x features)
Polynomial features of degree ≤ k from n inputs: C(n+k, k)
Trap: n=3: k=2 ⇒ 10, k=3 ⇒ 20. 20 params with 12 samples ⇒ underdetermined.
BIC = d ln m + m ln MSE: lower is better
Trap: Can be negative. Only the minimum matters.
Feature rescaling: LS predictions unchanged; ridge changes
Trap: x′=2x−1, y′=10y+5 ⇒ w′=5w, R² same, MSE ×100.
Fit y on x and x on y: w₁w₂ = R²
Trap: Lines coincide only if R² = 1.
Outliers pull the line; check residuals, remove bad data or refit
Past paper: BIC, m=50: A (d=3, MSE 0.40) = −34.08, B (d=6, 0.33) = −31.96 ⇒ A. B wins only if MSE < 0.316. With m=5000 ⇒ B.
Past paper: Data x=1..5, y=2,3,5,4,6: ŷ = 1.3 + 0.9x; w₁w₂ = 0.81 = R².

11Gradient descentpractice 5, 6 Q12–16

w ← w − η∇L; stop when ‖∇L‖ small, loss change small, or max iterations
Needs: η > 0.
Quadratic f = (λ/2)(w−w*)² ⇒ w⁽ᵗ⁾−w* = (1−ηλ)ᵗ(w⁽⁰⁾−w*)
Trap: Converges iff |1−ηλ| < 1, i.e. 0 < η < 2/λ. Best one-step η = 1/λ.
Several curvatures: η < 2/λ_max
Trap: ½(w₁²+9w₂²) ⇒ 0 < η < 2/9.
η too small: slow. Too big: oscillates or diverges. Plateau: decay η
Trap: Faster smooth drop after a change ⇒ η was increased.
σ′ = σ(1−σ). Chain rule: dy/dw₁ = (dy/dθ₂)(dθ₂/dθ₁)(dθ₁/dw₁)
Past paper: f=(w−2)²+1, w₀=5, w₁=3.8 ⇒ η=0.2; w₂=3.08, w₃=2.648; |w−2|<0.01 needs t=12. η=1 oscillates 5, −1.
Past paper: f=½x²−4x+12 from x₀=−2 ⇒ η=1 lands on x=4. ∇[(x₁−3)³σ(x₂)] at (−1,1) = (35.09, −12.58).

12Classificationpractice 5, 6 Q17–22

Logistic: ŷ = σ(wᵀx), class 1 if ŷ ≥ 0.5 ⇔ wᵀx ≥ 0
Needs: Boundary is a line or hyperplane.
BCE: −y ln ŷ − (1−y)ln(1−ŷ). Gradient (ŷ−y)x
Needs: Convex.
Trap: Largest |ŷ−y| ⇒ largest update. MSE + sigmoid stalls.
Softmax pᵣ = ezᵣ/Σezᵢ; CCE = −ln p_true
Needs: One-hot labels.
Trap: zᵢ/Σz fails with negatives. Integer labels imply false order.
Only logistic allowed, K classes ⇒ K one-vs-rest models
Trap: 3 classes ⇒ 3 models.
Boundary w₁x₁+w₂x₂+b = 0; w points to class +1
Trap: Plug a point (origin) to find the side.
Accuracy (TP+TN)/N. Precision TP/(TP+FP). Recall TP/(TP+FN). F₁ = 2PR/(P+R)
Trap: Imbalance: accuracy misleads. Missed faults dangerous ⇒ favour recall (lower threshold).
Hinge max(0,1−yf): y=−1 minimised for f ≤ −1. Log loss ln(1+e−yf): no finite minimiser
Past paper: Softmax (5.2, 3.6, −2.7) ⇒ (0.832, 0.168, 0.0003). TP=6, FP=2, FN=3 ⇒ P=0.75, R=0.667, F₁=0.706.

13Neural nets and ridgepractice 6 Q23+

Neuron φ(wᵀx); with σ it is logistic regression
h = φ(W₁ᵀx), y = W₂ᵀh. Params ≈ nH + Hp (+ biases)
Trap: 100·500 + 500·1 = 50,500.
ReLU [0,∞), sigmoid (0,1), tanh (−1,1)
No activations ⇒ the whole MLP collapses to one linear map
ReLU(x) − 2ReLU(x−1) + ReLU(x−2): triangle, peak 1 at x=1, zero outside [0,2]
Needs: One kink per hidden unit.
Ridge: L = MSE + α‖w‖², w = (XᵀX + αI)⁻¹Xᵀy
Needs: α ≥ 0.
Trap: Larger α shrinks w. Sensitive to feature units.

14Concept traps (mid-sem multiple choice)mid-sem

Linearity of expectation needs no independence; variance additivity does
Uncorrelated but dependent is possible (Y = X²)
Larger PDF peak ⇒ smaller σ; P(A=0) = 0 for continuous A
n = 30 is not automatically enough for the CLT
Calibration drift breaks the LLN conclusion
Using s instead of σ ⇒ t-distribution
Halving the margin of error ⇒ quadruple n
