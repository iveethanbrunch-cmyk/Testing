Counting and hypergeometric

Use when: Seen: practice 4 Q1, practice 2 Q6, practice 3 Q3.
Formula / fact
Conditions needed
Trap
Round table, n people: (n−1)! arrangements (fix one person)
NeedsRotations identical.
TrapNext to spouse among 20: 2·18!/19! = 2/19.
Choose k from n: C(n,k) = n!/(k!(n−k)!)
NeedsOrder does not matter.
Hypergeometric: P(exactly j faulty in k from N with M faulty) = C(M,j)C(N−M,k−j)/C(N,k)
NeedsDraw without replacement.
TrapChips: 30 total, 11 broken, test 5, exactly 1 faulty: C(11,1)C(19,4)/C(30,5).
Sample space of the count of faulty chips among 5 drawn: {0,1,2,3,4,5}
NeedsLimited by how many faulty chips exist.
TrapList values, not outcomes.
Groups by category: product of C(·,·) for each category, divided by C(total, group size)
NeedsClayton and Malaysia, male and female: 4 categories.
TrapCheck the chosen counts add to the group size.
Joint PMF from random draws (X reds, Y whites among 3 drawn from 2R, 3W, 4B): P = C(2,x)C(3,y)C(4,3−x−y)/C(9,3)
NeedsMarginals: sum the joint over the other variable.
TrapX and Y are not independent (sample without replacement).

Stuck? Try: Write the total number of equally likely outcomes first, then count the favourable ones.

Conditions needed
Trap

NeedsEvents independent, constant average rate.
Trapλ is for THE INTERVAL ASKED. Scale it first.

NeedsSame time unit on both.
Trap600/min over 200 ms: λ = 600 × (0.2/60) = 2. 1460/year over one day: λ = 4.
P(N=0) = e−λ
Trapλ=2 ⇒ 0.1353. λ=4 ⇒ 0.0183.

Gaussian tail comparisons and sample means

Use when: Seen: practice 2 Q2, practice 3 Q1, Q6, practice 4 Q7, mid-sem Q8.
Formula / fact
Conditions needed
Trap
P(X > t) = Q((t−μ)/σ)
NeedsX Gaussian.
TrapSource A (230, 5) vs B (225, 10) above 240: Q(2)=0.0228 vs Q(1.5)=0.0668. B more likely.
Lifetime ≥ 30,000: Sensor 1 (28000, 1000): Q(2)=0.0228. Sensor 2 (24000, 4000): Q(1.5)=0.0668
NeedsChoose the larger probability.
TrapChoose Sensor 2.
Sample mean of n Gaussian readings: X̄ ~ N(μ, σ²/n)
NeedsUse σ/√n as the SD.
TrapMid-sem Q8: (13.2−12)/(6/√64) = 1.6 ⇒ 1−Φ(1.6) = 0.0548 (Z-table Φ(1.6)=0.9452).
P(45 < X̄ < 52), σ=10, n=16: SD = 2.5, z from 0 to 2.8
NeedsQ(0) − Q(2.8)
Trap= 0.5 − 0.002555 = 0.4974.
Symmetric interval with probability p: μ ± z·σ/√n with Q(z) = (1−p)/2
Needs95% ⇒ z=1.96. 60% ⇒ Q(z)=0.2 ⇒ z≈0.84.
Trap95% of sample means: 45 ± 1.96(2.5) = (40.1, 49.9).
Required n so that |X̄ − μ| < σ/10 with probability 0.95: n = (1.96 × 10)²
Trap= 384.16 ⇒ n = 385. Round up.
Peak height of a Gaussian PDF is 1/(σ√2π): bigger peak = smaller σ
Trapf(0) is a density, not P(A=0). P(A=0) = 0 for both.

PDF with an unknown constant

Use when: Seen: practice 2 Q3, practice 3 Q4, practice 4 Q2.
Formula / fact
Conditions needed
Trap
Total area = 1 fixes the constant
Needs∫ f dx = 1 over the support.
Trapf = a(4−(x−38)²) on [36,40]: area = a·32/3 ⇒ a = 3/32.
Second condition (e.g. E[X] given) fixes a second constant
Needsf = a x^b on [0,1]: a = b+1, E = (b+1)/(b+2) = 0.6 ⇒ b = 0.5, a = 1.5.
CDF: F(x) = ∫ from lower limit to x. Write 0 below and 1 above
NeedsPiecewise.
TrapF(x) = x1.5 on [0,1].
P(X ≥ c) = 1 − F(c)
TrapSymmetric PDF about 38 ⇒ P(X ≥ 38) = ½ and E = 38.
E[X] = ∫ x f. E[X²] = ∫ x² f. Var = E[X²] − E[X]²
Trapf = 1.5x0.5: E[X²] = 3/7, Var = 3/7 − 0.36 = 0.0686.
Y = aX + b: E[Y] = aE[X] + b, Var(Y) = a²Var(X)
TrapY = 2X+1: Var = 4Var(X). °F = 1.8·°C + 32: VarF = 3.24 VarC.
Piecewise PDF read from a graph: area = 1 gives a; Y = g(X) gives a PMF by summing probabilities of regions
TrapP(X = 1) = 0 for continuous X.

Joint distributions: independent? uncorrelated?

Use when: Seen: practice 3 Q5, mid-sem Q3, Q15, practice 4 Q5.
Formula / fact
Conditions needed
Trap
Independence test: P(x,y) = P(x)P(y) for every cell. One failing cell proves dependence
Trapp(0,1)=p(1,0)=p(2,1)=1/3: P(X=0,Y=0)=0 but P(X=0)P(Y=0) = 1/9. Dependent.
Uncorrelated test: Cov = E[XY] − E[X]E[Y] = 0
TrapSame example: E[X]=1, E[Y]=2/3, E[XY]=2/3 ⇒ Cov = 0. Uncorrelated but dependent.
X uniform on {−1,0,1}, Y = X²: E[XY] = 0 ⇒ uncorrelated, but Y is a function of X
TrapZero covariance never proves independence.
Conditional PDF: f(y|x) = f(x,y)/fX(x), fX(x) = ∫ f(x,y)dy
NeedsFix x, integrate y over its limits at that x.
Trapf = 2 on 0<y<x<1: fX = 2x, f(y|x) = 1/x, so P(Y < x/2 | X=x) = (x/2)/x = ½.
E[aX+bY] = aE[X] + bE[Y]. Cov(F, aF+b) = a Var(F)
NeedsLinearity of expectation needs no independence.
TrapPractice 4 Q5: prove it from the integral definition.

Binary detection with Gaussian noise

Use when: Seen: practice 4 Q3, practice 5 mixed.
Formula / fact
Conditions needed
Trap
Decide "0" if fY(y|X=−1)P(X=−1) > fY(y|X=1)P(X=1)
NeedsY = X + N, N ~ N(0,σ²).
Threshold: T = (σ²/2) ln(P₀/P₁)
NeedsGaussian likelihoods with equal σ, means −1 and +1.
TrapP₀ = 2P₁, σ² = 1/16 ⇒ T = (1/32)ln 2 = 0.0217.
P(error) = P₀ Q((T+1)/σ) + P₁ Q((1−T)/σ)
Needsσ = 0.25 here.
TrapQ(4.09) and Q(3.91) are about 2×10⁻⁵ and 4.6×10⁻⁵. Use the Q table.
Equal priors ⇒ T = 0
TrapUnequal priors move the threshold toward the less likely symbol.

Stuck? Try: Take logs of both sides, collect y on one side, and you get a straight threshold on y.

Regression computations and properties (AI practice exam)

Use when: Seen: practice 6 Q1, Q3 to Q9, mock Q3 and Q6.
Formula / fact
Conditions needed
Trap
Residual ei = yi − ŷ_i. MSE = (1/m)Σei²
TrapLeast-squares fit with bias: Σei = 0 and Σxi ei = 0 and Σŷ_i ei = 0.
Recover lost residuals using Σe=0 and Σxe=0 (two equations, two unknowns)
NeedsFitted by least squares with a bias.
TrapThen yi = ŷ_i + ei.
Rescale the features: least squares gives the same predictions, ridge does not
NeedsSame α.
TrapRidge penalises ‖w‖², which changes when units change.
x′=2x−1, y′=10y+5: w′ = 5w, R² unchanged, MSE × 100
NeedsAffine changes of x and y.
Trapb′ = 10b + 5w + 5.
Fit y on x and x on y: w₁w₂ = R², lines coincide only if R²=1
NeedsS_xy, S_xx, S_yy. w₁ = S_xy/S_xx, w₂ = S_xy/S_yy.
TrapBoth lines pass through (x̄, ȳ). SSE = S_yy − S_xy²/S_xx.
R² = 1 − SSE/SST. Higher is better on training data
NeedsSST = Σ(y−ȳ)².
TrapR² on training data always improves with more features. Use validation or BIC.
Fewer samples than parameters: w† = Xᵀ(XXᵀ)⁻¹y (minimum norm)
NeedsUnder-determined.
Trapx=(1,2), y=5: w† = (1,2). Prediction at (2,1) = 4, but another zero-error w=(5,0) predicts 10. Zero training error says little.
Features like cos x, sin x, x²: still linear regression
NeedsLinear in the parameters.
TrapDesign matrix columns (1, cos x, sin x). With four equally spaced phases XᵀX is diagonal.
Outliers pull the MSE line toward themselves
TrapSpot large residuals, check the data, remove or use a robust loss, then refit.
Polynomial features of degree ≤ k from n inputs: C(n+k,k)
Needsn=3: k=2 ⇒ 10, k=3 ⇒ 20.
Trap20 parameters with 12 samples is under-determined. Training MSE ≈ 0. Do not trust it.

Gradient descent questions

Use when: Seen: practice 5 mixed, practice 6 Q12 to Q16.
Formula / fact
Conditions needed
Trap
Training loop: initialise w, repeat w ← w − η∇L until a stopping rule
Needsη > 0.
TrapState the stopping rule: gradient small, loss change small, or max iterations.
f = ½x² − 4x + 12: ∇f = x − 4. One step to the minimum needs η = 1
NeedsQuadratic with curvature 1.
TrapGeneral: f = (c/2)x²-type ⇒ best one-step η = 1/curvature.
f(w) = (w−2)²+1: w⁽ᵗ⁾ − 2 = (1−2η)ᵗ(w⁽⁰⁾−2)
Trapw⁽⁰⁾=5, w⁽¹⁾=3.8 ⇒ η=0.2. Then 3.08, 2.648. η=1 oscillates 5, −1 forever.
Convergence from every start: |1 − ηλ| < 1 for every curvature λ
Needsf = ½(ω₁² + 9ω₂²) ⇒ 0 < η < 2/9.
TrapThe steepest direction limits the step size.
Learning rate choice: start moderate, watch the loss curve, decay when it plateaus
NeedsToo big: oscillate or diverge. Too small: slow.
TrapA faster, still smooth curve after a change means η was raised.
Gradient of f(x₁,x₂) = (x₁−3)³σ(x₂): ∂/∂x₁ = 3(x₁−3)²σ(x₂), ∂/∂x₂ = (x₁−3)³σ(x₂)(1−σ(x₂))
Needsσ′ = σ(1−σ).
TrapAt (−1,1) ≈ (35.09, −12.58).

Classification questions

Use when: Seen: practice 5 mixed, practice 6 Q17 to Q22.
Formula / fact
Conditions needed
Trap
Why not linear regression for classes: unbounded output, wrong loss, integer labels imply order
TrapState at least two reasons.
K classes with only logistic regression: K one-vs-rest models
Needs3 classes ⇒ 3 models.
TrapPick the class with the largest probability.
Softmax uses exp: positive outputs, sum to 1. zᵢ/Σz fails with negatives or a zero sum
Remove all activations from an MLP: it collapses to a single linear model
NeedsComposition of linear maps is linear.
BCE per sample: −y ln ŷ − (1−y) ln(1−ŷ). Gradient (ŷ−y)(x,1)
Needsy ∈ {0,1}.
TrapThe sample with the largest |ŷ−y| has the largest gradient. Confident wrong predictions dominate.
Hinge loss max(0, 1−yf): for y=−1 minimised for any f ≤ −1 (greatest such value is −1). Log loss ln(1+e−yf): no finite minimiser
Linear classifier sign(w·x+b): boundary w₁x₁+w₂x₂+b=0, w is normal to it
NeedsSide with w·x+b ≥ 0 is class +1.
Trapw=(2,−3), b=1: line x₂ = (2/3)x₁ + 1/3.
Metrics at a threshold: accuracy (TP+TN)/N, precision TP/(TP+FP), recall TP/(TP+FN)
NeedsRaise the threshold: precision up, recall down.
TrapIf a missed fault is dangerous, choose the lower threshold (higher recall).
ReLU network: f = ReLU(x) − 2ReLU(x−1) + ReLU(x−2) is a triangle with peak 1 at x=1, zero outside [0,2]
NeedsPiecewise linear, one kink per hidden unit.
